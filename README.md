# VIT Bhopal Mess Menu

A simple terminal-based Python project for checking the weekly food menu of two VIT Bhopal hostel messes.

## Messes
- Mayuri Boys Mess
- JMB Boys Mess

## Meals
- Breakfast
- Lunch
- Dinner

## Features
- Browse the weekly menu.
- Check today's menu.
- Select a mess, day and meal.
- Handles invalid choices.

## Run
```bash
python main.py
```

## Test
```bash
python -m unittest discover -s tests -v
```

No external packages are required.
