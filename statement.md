# Problem Statement

Hostel students need an easy way to check the food served in their mess.

## Scope

This project provides a simple terminal-based menu system for two VIT Bhopal hostel messes. A student can select a mess, day and meal to see the available food. The system can also show the menu for the current day.

## Target Users

VIT Bhopal hostel students.

## Main Features

1. Browse the weekly menu.
2. Check today's menu.
3. Select from two messes and three meals.
